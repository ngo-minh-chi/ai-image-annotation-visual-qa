# AI Image Annotation & Visual QA

A portfolio project demonstrating structured image annotation, visual question answering, prompt adherence evaluation, ambiguity handling, and annotation quality control.

## Project Overview

This project simulates a real-world workflow for preparing and reviewing image data for AI training and evaluation.

The dataset contains structured annotations describing:

- Objects and object counts
- Visual attributes
- Image types
- Visual question-answering cases
- Evidence supporting answers
- Confidence scores
- Annotation verification status
